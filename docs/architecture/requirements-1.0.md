## 3. What 1.0 needs and is not engineering

These points are not in D13, but 1.0 cannot be declared without them:

- **Real use outside the team (D12; ADR-0019).** There is none. The only use case is `examples/agent-memory/`, which the minutes call an internal use case (minutes §2.4 and D12). ADR-0019 conditions charging on "a 1.0 with a stable format, migrations and real users in production". It is missing that someone outside the team uses the API and that it is recorded.
- **The owner's declaration (D12).** 1.0 is declared only after D13 and real use. Freezing the export format and promising semver for the API are promises to users; the minutes do not leave them to this document, and they are not made here.
- **Outside D13, but pending to accept any external contribution**: the owner's approval of the text of the CLA (D15). There is a draft without force in [`docs/legal/cla-draft.md`](../legal/cla-draft.md).

**1.0 is not declared.** No document in the repository declares it, and this one does not either.
